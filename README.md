# Pumpkin_build

把 [Pumpkin](https://github.com/Pumpkin-MC/Pumpkin)（Rust 写的 Minecraft 服务端）编译成各平台可直接运行的二进制，并提供安卓 App「**南瓜坞**」——一键下载、启动、管理服务端。

## 快速开始

1. 去 [Releases](../../releases) 页，找**最新的带 `pumpkin-shell.apk` 的发布**，下载安装
2. 打开 App →「更新」页 → **检查更新** → **下载最新版本**
3. 切到「运行」页 → 点 **启动**，界面上会显示联机地址

> 后续更新只需 App 内「设置 → 检查更新」即可，不用再手动下载 APK。

详细安装与使用说明见 → **[ANDROID.md](ANDROID.md)**

## 南瓜坞 App 功能一览

| 功能 | 说明 |
|---|---|
| **四页界面** | 运行（状态 + 控制台）、更新（版本管理）、插件、设置 |
| **液态玻璃底栏** | 半透明背景模糊 + 边缘光泽 + 倾斜流动高光 |
| **明暗 × 配色** | 深色 / 浅色 / 跟随系统，7 套配色自由组合 |
| **插件商店** | 从商店一键装插件（**不需要 Root**）、启用 / 停用 / 卸载；插件改的设置项集中在「插件」页 |
| **版本管理与回滚** | 多版本共存，可随时切换回旧版本 |
| **应用内自更新** | App 自身也能在应用内下载更新，无需跳浏览器 |
| **双启动模式** | 普通模式（免 Root）/ Root 模式（Magisk，不改 SELinux） |
| **下载自动回退** | 直连不通时自动尝试多个镜像源，失败自动重试 |
| **前台服务** | 切后台或锁屏服务端继续运行 |

### 插件

插件是**独立的代码**（编译成 dex，运行时加载），用来加本该属于第三方的小功能，
而不是都往主程序里塞。目前商店里有一个示例插件「控制台字号」——
把运行页控制台的日志文字按 0.5~3 倍缩放。

装插件走「插件」页 →「插件商店」→「安装」，**全程不需要 Root**，也不需要手动放文件：
App 只是往自己的私有目录写 dex。想写插件见 [`docs/dev/plugins.md`](docs/dev/plugins.md)。

## 服务端二进制

Releases 里也提供各平台的服务端二进制，可单独下载使用：

| 文件 | 平台 |
|---|---|
| `pumpkin-android-arm64-<日期>` | Android arm64（南瓜坞 App 下载的就是它） |
| `pumpkin-linux-x86_64-<日期>` | Linux x86_64 |
| `pumpkin-windows-x86_64-<日期>.exe` | Windows x86_64 |

下载后直接运行即可（Pumpkin 是 Rust 编写的原生二进制，不需要 Java）。

## 常见问题

**Q：安装 APK 时提示「不允许安装未知应用」？**
到系统设置里找到对应来源（如「文件管理」或「浏览器」），开启「允许安装未知应用」即可。

**Q：App 里下载服务端为什么要下 119MB？**
那是 Pumpkin 服务端的 aarch64 原生二进制，包含完整的 Rust 运行时。App 本身只有约 1MB，两者是分开的。

**Q：下载进度不动 / 连不上 GitHub？**
国内网络直连 GitHub 可能不通。App 会自动尝试多个镜像源；如果仍然失败，可在「设置」页手动填写镜像地址。

**Q：只支持 arm64 吗？**
南瓜坞 App 只支持 **arm64（64 位 ARM）** 手机。32 位 ARM、x86 模拟器无法使用。服务端二进制另有 Linux / Windows 版本。

**Q：切换版本时提示要先停止服务端？**
服务端运行时会占用文件。先点「停止」，再切换版本即可。
